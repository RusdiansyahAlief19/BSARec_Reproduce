# Log index

## CP1

`CP1/` contains the preserved training and checkpoint-evaluation logs. Six primary LastFM training logs are not available as standalone files; their saved test outputs are in the executed CP1 notebook and summarized in `../results/CP1/`.

## CP2

`CP2/pilot/` contains seed-42 time-aware logs from an earlier pilot. The final paired results use the executed notebook in `../notebooks/CP2/` plus its captured outputs; do not treat the pilot log files as a substitute for the complete three-seed paired run.

Model checkpoints (`*.pt`) are excluded from Git.
